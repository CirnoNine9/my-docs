# 关于本项目

## 项目目标

练习从 Markdown 文档到公开网站的自动化发布，并通过构建日志了解每个环节。

## 技术组成

| 工具 | 作用 |
| --- | --- |
| Markdown | 编写文档内容 |
| MkDocs Material | 将文档构建成静态网站 |
| GitHub Actions | 自动执行安装、构建和部署 |
| GitHub Pages | 托管并提供网站访问地址 |

源码保存在仓库中；构建生成的网站文件由工作流上传并部署。更多操作见[使用指南](guide.md)。

## 实践体会

这次实践让我把文档源码、构建产物和部署后的网站区分开来。推送后查看 Actions 的任务状态，再打开网站确认变化，比只检查一次构建成功更能发现发布或缓存问题。
